# Performance Marketing Dashboard

Google Sheets RAW 데이터를 읽어 전일/전주/전월 성과를 비교하는 Streamlit 대시보드입니다.

## 포함 기능
- Google Sheets CSV 자동 연결
- 기준일 선택
- 전일 / 전주 / 전월 비교
- 동일 진행일수 기준 전주/전월 비교
- 매체 다중 선택
- 캠페인 다중 선택
- CPA + 전환수 차트
- 광고비 + 전환수 차트
- 매체 가로 / 지표 세로 비교표
- 변화율: 빨간 ▲ / 파란 ▼
- 자동 성과 코멘트
- 캠페인 드릴다운
- Google Sheets 5분 캐시 및 수동 새로고침

## Streamlit Community Cloud 배포
1. GitHub repository 생성

3. Streamlit Community Cloud에서 GitHub repository 연결
